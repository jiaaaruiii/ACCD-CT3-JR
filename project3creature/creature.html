Overview

This project is an interactive visualization experiment based on ESP32 and TouchDesigner. It uses real-time atmospheric pressure data to drive a rainfall effect: when the pressure rises, it starts raining in the virtual environment; when the pressure drops, the rain stops.

System Architecture

The system is composed of three parts:

  • ESP32 + Sensors: The ESP32 collects local data and sends it to the Adafruit IO platform via WiFi.
  • Adafruit IO: Serving as a cloud-based data exchange platform, it handles data upload and subscription. My device and a classmate's device send data to each other and subscribe to each other’s datasets, enabling real-time data sharing.
  • TouchDesigner: Receives serial data and visualizes different effects based on the values.
