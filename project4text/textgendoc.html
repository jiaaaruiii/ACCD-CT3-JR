TextGen Doc

Intro

This project fetches data from two different APIs, merges the results, trains a simple Markov chain model on the combined text, and then generates new text from it.

Data Sources

Using the API provided by The New York Times:

https://developer.nytimes.com/

I selected two different sections—World News and Arts—to combine. Both provide a results list, and this project mainly uses the abstract field from each item as the training text.

Implementation of Style Fusion

function fetchSourceText(){
    const fetchWorldPromise = fetch(sourceURL);
    const fetchArtsPromise = fetch(sourceURL2);

    // Promise.all ensures both requests complete before processing
    Promise.all([fetchWorldPromise, fetchArtsPromise])
        .then(responses => {
            return Promise.all(responses.map(res => res.json()));
        })
        .then(dataArray => {
            const [worldData, artsData] = dataArray;

            // Train model with World News (Source 1)
            worldData.results.forEach(news => {
                if (news.abstract) processText(news.abstract);
            });
            
            // Train model with Arts News (Source 2) - fusion happens here
            artsData.results.forEach(news => {
                if (news.abstract) processText(news.abstract);
            });

            inputText.disabled = false;
            generateButton.disabled = false;
            console.log("✅ Model successfully fused World and Arts patterns.");
        })
        .catch(error => {
            console.error('Error fetching source texts:', error);
        });
}

In fetchSourceText(), two fetch requests are initiated simultaneously using Promise.all:


Promise.all([fetch(sourceURL), fetch(sourceURL2)])

Once both responses are returned, their JSON data is processed together. This ensures that content from both sources is used simultaneously for text generation.
